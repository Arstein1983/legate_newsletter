# Бот для рассылок Telegram

Управление идёт через **бота на aiogram**, сами сообщения отправляются **с аккаунта администратора** через Telethon (не от имени бота). Группы получателей, шаблоны и история хранятся в **MySQL**.

## Что умеет

- Группы получателей: username (`@tag`) или номер телефона
- Несколько независимых групп
- Сохранение сообщений (текст, фото, видео, файлы) и выбор шаблона перед рассылкой
- Рассылка от аккаунта админа, с паузой между сообщениями
- История запусков и лог ошибок по каждому получателю
- Импорт списка из `.txt` / `.csv`

## Подготовка

1. Python 3.11+
2. MySQL 8 (можно поднять через Docker)
3. Бот от [@BotFather](https://t.me/BotFather) — токен
4. `api_id` и `api_hash` приложения: [https://my.telegram.org/apps](https://my.telegram.org/apps) — без них нельзя писать от имени аккаунта

Скопируйте `.env.example` в `.env` и заполните:

```env
BOT_TOKEN=123456:ABC...
ADMIN_IDS=123456789
MYSQL_HOST=127.0.0.1
MYSQL_PORT=3306
MYSQL_USER=newsletter
MYSQL_PASSWORD=newsletter
MYSQL_DATABASE=newsletter
TELEGRAM_API_ID=123456
TELEGRAM_API_HASH=...
SEND_DELAY_SECONDS=4
```

`ADMIN_IDS` — Telegram user id админов через запятую. Если id неизвестен, поставьте `0`, напишите боту `/start` — он ответит ваш id.

### MySQL через Docker

```bash
docker compose up -d
```

Либо создайте базу сами:

```sql
CREATE DATABASE newsletter CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

Таблицы создаются автоматически при старте бота.

## Запуск

```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
python main.py
```

На Linux/macOS: `source venv/bin/activate`, `cp .env.example .env`.

## Первый вход

1. Откройте бота в Telegram, `/start`
2. **Настройки → Войти в аккаунт админа**
3. Введите номер телефона этого аккаунта и код из Telegram (при 2FA — облачный пароль)
4. Создайте группу, добавьте `@username` или телефоны
5. Сохраните сообщение-шаблон
6. **Рассылка** → группа → шаблон → запуск

Сообщения у получателей придут **от вашего аккаунта**, диалог с ботом получатели не увидят.

## Формат получателей

Каждая строка — один человек:

```
@username
+79001234567
username,Иван
+79001234567,Мария
https://t.me/username
```

## Важно про Telegram

- Аккаунт может писать не всем подряд: сработают контакты, взаимные переписки и открытые личные сообщения. Иначе будет ошибка в логе.
- При отправке по номеру контакт временно импортируется в адресную книгу аккаунта.
- Слишком частая рассылка приводит к FloodWait / PeerFlood и ограничениям на аккаунт. Не ставьте паузу меньше 3–4 секунд.
- Получатели должны быть согласны получать сообщения. Массовый спам нарушает правила Telegram.

Сессия аккаунта хранится в `sessions/admin.session`. Не публикуйте этот файл и `.env`.
